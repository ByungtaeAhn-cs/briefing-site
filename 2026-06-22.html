김문정(배움의 달인), Fable5 후폭풍과 로컬 LLM 실전 검증 주간

Fable5 사태 이후 각국 소버린 AI 정책 논의가 가열되는 가운데, **로컬 LLM 워크스페이스** 셀프호스팅 영상과 리치고 파이낸스 MCP 작업을 병행하며 이번 주 멀티 트랙 활동 전개.

신규 영상 두 편 공개 — 셀프호스팅 local LLM AI workspace 소개, 그리고 퓨디파이가 만든 **Odysseus 설치·활용** 가이드(Tavily API는 settings→search→Deep research에서 연결 필요). 모델 시장 단신으로 **GPT-5.6이 Fable 대비 1/3 가격에 더 우수**하다는 벤치 언급, superGrok heavy 99달러 라인업, Grok 빌드에 compose 2.5 커서모델 추천 정리. Mac Studio M5는 10월 이후로 출시 연기 공식화. 로컬 모델을 동일 조건에서 비교해 본 결과 **Claude Code보다 opencode 하네싱이 더 양호**하다는 체감 공유, 본인은 요즘 거의 codex만 사용 중이며 에이전트 무용론까지 자문하는 단계.

제가 local 모델을 다양하게 쓰면서 실험중인데, 같은 로컬모델을 claude code에서 쓰는거랑 opencode에서 쓰는 것 비교했을때 opencode가 더 좋은 것 같네요. claude 하네싱이 별로란 글이 있던데… 요즘 제 느낌이랑도 비슷하네요
그래서 opensource 모델에 비전이 있다고 봅니다. 저는 claude 구독을 끊었느데.. 제가 클로드와 했던 작업에 대한 메모리를 가지고오지 못해요

또한 26~27일 리치고 세미나에서 직접 만든 **리치고 파이낸스 MCP**와 정제 데이터 중요성 발표 예정, 삼성전자·SK하이닉스 비교 리포트 공유하며 TTM PER·Forward PER 기반 판단 프레임 제시. Fable5 후폭풍으로 국가 단위 AI 데이터센터·메모리 반도체 수요 증가 전망까지 거시 관점 추가.

오픈소스 하네스와 codex 단일 체제로의 회귀 신호는 에이전트 프레임워크 선택을 재검토 중인 독자에게 직접적인 비교 근거, GPT-5.6 가격·성능 역전과 Mac Studio M5 연기는 단기 워크스테이션 투자 결정에 영향 있는 정보.
