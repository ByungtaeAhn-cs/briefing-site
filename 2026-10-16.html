2018년 기준 라인 센서 전체 데이터를 투입해도 **이상탐지 예측력이 0에 수렴**한 상태였다는 회고. 정상 구간에서 신호가 갑자기 튀는 데이터 특성과 수백 대 규모의 장비가 난제의 원인으로 지목됨. 다변량분석·신경망에 대한 현업의 누적된 불신, SW연구소를 DS 부문 산하로 옮긴 시도가 조직개편으로 끝난 경위도 언급. 현업이 듣고 싶은 내용과 달리 세미나에서 jacobian 풀이와 선형대수를 강조해 어긋났던 사례도 소개.

허민, 그록봇 행사 추진과 Claude 이주 권고

argon4 발표 공유와 함께 **그록봇 카페** 행사 수요 조사 개시. 커서카페 형식을 본뜬 행사로 SpaceX 그록팀과 조율 중이며, 공식 굿즈 배포와 그록봇 팀의 사용성 세션 구상 언급.

도구 선택은 **Claude로 이주 권고**(본인은 이주 완료). 다만 코덱스앱은 여전히 우수하다는 평가. 그록봇은 음성채팅 응답 속도를 호평함. 수입의 20%를 구독료에 쓰고 할당량을 다 쓸 때까지 6개월 몰입하라는 **에이전트 숙련 투자론** 제시. 롱블랙 AI 버전 서비스 개발 착수. 영상편집 기술을 AI 시대 생존 스킬로 지목.

사실 클로드 코드,OpenClaw,코덱스 산전수전 다 겪은 사람이 무조건 그록봇이나 봇들 더 잘 쓸수밖에 없어요.

샘호트만 @ai.sam_hottman, Claude Code 병렬 세션과 LLM 앞단 필터 다이제스트

링크 큐레이션 7건과 강의 전사 활용 코멘트 1건. Claude Code 병렬화 업데이트 2건이 중심.

- **Claude Code 병렬 세션**: 병렬 작업을 요청하면 작업마다 nested session이 생성되고, 결과만 메인 세션으로 반환됨. 데스크톱 앱에서는 여러 세션을 나란히 실행하고 각 진행 상황 확인 가능.
- **단계형 AI 다이제스트**: 수백 개 출처를 매일 압축하는 구조. plain code로 오래된 글과 이미 본 항목을 먼저 제거 → Jev 선별 → 통과한 항목만 Haiku 5.5에 전달.
- REA MCP: 앱·APK·firmware를 역분석하는 무료 MCP server. `npx rea-agents setup`으로 Claude Code·Codex·Cursor·Gemini CLI와 연동하며, 소유하거나 분석 허가를 받은 software만 대상.
- Claude Motion `/motion` 20초 설명 영상 템플릿 공유(Team·Enterprise 한정). Fish Audio 신모델 drama3 공개.

강의 전사하는거 잘 응용하면 써먹을 곳이 진짜 정말 많은 것 같습니다. ai가 읽게 좋게 만든 다음에 시스템이나 이런거 만드는데 활용하면 몸에 좋습니다.

다이제스트 사례는 LLM에 넘기기 전에 규칙으로 잡음을 거르는 구조. 본 브리핑 파이프라인의 noise_filter 설계와 같은 접근의 외부 사례임. nested session 반환 방식은 멀티 에이전트 워크플로에 바로 적용 가능한 기능.
