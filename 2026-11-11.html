코드 작업은 **Claude 데스크탑앱 Opus-5.5 medium**으로 전환, Codex는 20달러 요금제만 유지 방침. 복잡하지 않은 작업은 **Cursor 클라우드 에이전트** 단독 처리. 멀티 오케스트레이션이 필요한 경우에만 herdr 사용(운영은 herdr봇과 Engineering Lead 봇이 분담). Sakutto 기반 로컬 번역기 **후딱(huttak)** GitHub 공개. 기본 언어쌍을 한↔영으로 변경, PLaMo 브라우저 엔진과 로컬 서버 중 선택하는 구조, 유튜브와 X 영상 번역까지 확장. 후속으로 DeepL 확장 리버스 엔지니어링(15,000자 제한 해소 목적) 구상. 모션그래픽 도구로는 페이블 추천.

코드 작업은 당분간 클로드 데스크탑앱에서 Opus-5.5 미디움으로 진행 ㄱㄱ
제가 뭐하나 말하자면 핫한 개발자들은 커서로 다시 넘어올겁니다.
