허민, 그록봇·Hermes 봇 생태계 실전 검증과 AI 격차론

하루 종일 봇 플랫폼 실사용 리포트를 연속 투하함. **Hermes 봇모드 업그레이드**로 프로필=봇 개념이 통합되어 생성·활용 난이도가 낮아진 점을 첫 신호로 짚음.

본인 봇 티어를 Hermes agent → Grok Bot → Buzz 순으로 정리하고, 그록봇 가상컴퓨터에 Herdr 설치 후 grok·cursor·hermes·warp CLI를 전부 올려 테스트 중임을 공유함. 오케스트레이션 구성도 구체적으로 제시 — Cursor(Opus 5)가 설계와 최종 리뷰, Grok 빌드의 Grok 4.6이 1차 구현, Codex의 gpt-5.6-sol이 테스트와 타 파일 구현, Hermes의 solar-pro4가 한글 정리와 교차검증 담당. 결제 가능 플랫폼 연결 시 그록봇이 결제까지 자율 수행하는 단계 도달을 지적함. GLM은 데일리 드라이버로 손색 없는 수준으로 평가. 일정 정보로는 다음주 목요일 GPT 아스트라 발표 예정, GROK-4.7 출시 견제 목적으로 해석함.

지금부터는 AI를 사용하는 사람과 그렇지 않은 사람의 격차는 더 벌어질것이며, AI를 초보수준으로 활용하는 사람과 잘 활용하는 사람의 사용사례는 완전히 차원이 다른수준의 사용성을 보일겁니다
이건 openclaw이후에 또한번 엄청난 변화를 가져올겁니다.

단일 에이전트 대신 격리된 메모리·세션을 가진 다중 봇의 병렬 협업으로 전환하는 구체적 레시피 제시라는 점에서 참고 가치 있음. Herdr(herdr.dev) 기반 멀티 CLI 스택과 모델별 역할 분담은 로컬 오케스트레이션 설계에 바로 대입 가능한 레퍼런스임.

김문정(배움의 달인), 그록봇 에이전트 공유 시대의 첫 실사용 보고

Grok이 봇(에이전트)을 GPT처럼 공유 가능하게 바뀐 직후, 직접 만든 **Project Manager Bot** 템플릿을 방에 공개함. 이 방에 에이전트 4개를 실제로 투입해 운영 중임.

프로젝트를 말하면 봇이 기존 에이전트에 신규 에이전트를 더해 채널까지 자동 생성함. 유튜브 기획 채널을 스스로 만들어 회의·스크립트·썸네일까지 산출했고, 대화 내용을 정리해 카드뉴스로 올리는 것도 에이전트 자율 수행임. 단순 프롬프트가 아니라 **workflow 통째 공유**라는 점이 GPT 공유와의 결정적 차이임.

그록봇은 완전히 workflow 공유가 가능해보여서 그 활용도가 어마 무시 할 것 같네요… 아마 이 봇을 판매할 수 있게 될 것 같습니다.

에이전트 마켓 형성 가능성과 공무원 겸직 허가 문제까지 짚은 점이 주목할 대목. 비개발자 대상 에이전트 구축 경로가 Claude Cowork·ChatGPT Work 바깥에서 먼저 열리고 있다는 신호임.

김문정(배움의 달인), X 트렌드 큐레이션과 로컬 LLM·과금 실측

매일 X 최다 확산 AI 뉴스를 정리해 공유하는 루틴 유지 중. 8/29자 브리핑에서 OpenAI의 Cursor 공급 중단(SpaceX 인수 후 파트너십 종료, 직접 모델 접근 11월 12일까지), Cursor CEO 발언 기준 OpenAI 모델 트래픽 약 5%, Anthropic의 Claude 단독 소형 모델 정렬, Claude Code가 웹 요약만으로 코드 실행에 걸릴 수 있다는 연구를 함께 전달함.

과금 실측도 구체적임. 그록봇을 X에 연결하면 개발 API **100달러 무료 크레딧** 지급되어 기존 3.5불이 103.5불로 증가함. 그록 슈퍼헤비 900달러대에 커서 울트라 월 200달러 조합 관점 제시. 로컬 쪽은 GLM-5.3을 M5 128GB에서 구동 가능하다고 보고 unsloth GGUF 링크 공유, 다만 사용성 기준으로는 MLX 구동 우선 권장. 음성 입력은 whisper flow, 메인 도구는 다중 모델·모바일 지원을 이유로 buzz 사용.

일단 O M L X로 구동 가능한지 확인 후에 저라면 O M L X로 하는 게 사용성이 좋을 것 같긴 합니다

요금·크레딧·하드웨어 조합을 숫자로 제시한 드문 사례. GLM-5.3 로컬 구동 후보와 Cursor 모델 공급 리스크를 같은 날 함께 확인할 수 있는 대목임.
