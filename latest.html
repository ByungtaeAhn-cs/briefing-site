AGI/ASI 논문과 GLM 5.2 오픈소스 공개가 화두였던 ai-friends 단체방에서, 이제현 연구원은 자신의 에이전트 운영 방식을 공유함. 다담주 #aifrenz 학회 발표를 앞둔 시점의 실전 경험담임.

핵심 메시지는 **SKILL.md 대신 .py 스크립트**로의 회귀임. PDF 처리는 `pymupdf + Gemini` 조합으로 텍스트·이미지 분리 후 md/html 변환, 주제분류·연관분석도 파이썬 코드로 선처리하고 모호한 부분만 LLM에 위임하는 구조임. 확률적 오류와 토큰 비용을 동시에 줄이는 전략임. Anthropic·OpenAI·Google API가 동시에 끊겼을 때 qwen·gemma fallback을 깔았으나 품질 격차로 한 번도 전환 안 됨. **소버린 AI는 Opus·GLM 급 모델 확보가 전제**라는 입장임. 자체 개발 중인 Paper Banana는 텍스트 묘사 시 NanoBanana 생성, 수치 데이터 시 Matplotlib 코드 실행으로 듀얼 모드 운영함.

웬만한 작업은 SKILL.md가 아니라 .py로 만들어 놓고 그걸 실행하라고 했더니 확률적 오류도 안나고 토큰도 안먹고 좋네요. SKILL은 UI + 모호함 처리용으로만 써도 충분히 훌륭한 것 같아요.
메타인지가 정말 중요한게, 그렇게 할 수 있어도 결국 task마다 필요한 품질과 녹아나는 토큰비용을 알고 이걸 갖다가 최적화하는 영역을 찾아야 해서...

Anthropic Skills 마케팅이 한창인 시점에 현장 연구자가 **SKILL의 역할을 UI·모호성 처리로 축소**하고 결정론적 작업은 코드로 회귀한 사례임. 토큰 비용과 신뢰성의 트레이드오프를 task 단위로 메타인지해야 한다는 운영 원칙 제시임.

허민, Fable-5 충격과 프롬프트 방법론의 종언

이번 주 ai-frontier 방의 화두는 OpenAI Fable-5 등장과 그로 인한 시장 재편이며, 허민은 Durov·Sam Altman 측근·Satya Nadella 트윗을 연달아 공유하며 기업 단위 에이전트 도입 가속화 지적함. 흐름을 모델 경쟁력·국가 전략·실사용 방법론 세 축으로 정리함.

핵심 주장은 **프롬프트 방법론의 무용화**임. Fable-5 이후 정형화된 기법보다 도구 자체에 물어 판단을 위임하는 "토큰맥싱" 접근이 더 나은 산출. 동시에 **목적성 우선** 강조 — 해외 이주 후 영어 문제 해결이라는 절박한 목적이 본인의 AI 사용성을 극대화한 경험 공유. 한국 모델 경쟁력 격차 확대와 중국 모델 추격세 우려, 한국 입지로는 소프트웨어 개발 영역 집중 권고. 현시점 **Codex 사용성** 호평.

방법론 적인것보다 더 중요하게 느껴지는건 목적성인것 같아요
fable-5 같은 모델을 미국과 협력국가에만 제공한다고 한다면 진짜 큰일이 벌어질수 있을것 같다는 생각이 드네요

김문정(배움의 달인), 6월 말 행사 일정과 GPT-5.5 규제 파장 정리

**'주식 리치고' 런칭 세미나(6/26-27)** 파트너 게스트, **CMDS LLM Wiki Forum**(6/27 오전) 연사로 같은 주말 동시 참여 예정. 참석자 무료 사용권·MCP 제공 예고와 방원 초대 의사 전달함.

핵심 화두는 **GPT-5.5 규제 가능성**. fable5 사례처럼 막힐 수준이라는 관측 공유, Anthropic 공식 성명을 그대로 옮기며 OpenAI GPT-5.5도 동급 기능 보유 사실 강조함. 파장으로 미국 외 사용자의 구독 진입장벽 상승, 중국 오픈소스 정책 기반 **local LLM 흐름 가속**, 애플 주가 상승 전망, 소버린AI 대비 파인튜닝 우위론까지 시장 변화 시그널 다층 정리함. 부수적으로 리오시 자체 모델 제작, Codex Goal/Pet/원격제어 기능 소개도 곁들임.

GPT5.5도 fable5 처럼 막힐 수 있는 수준이라네요 미국인이 아닌 이상 GPT5.5 이상의 모델을 현재의 구독료로 사용하기는 어려워지는 듯한 느낌입니다. 중국은 오픈소스 정책인데, local LLM 흐름이 의외로 빨라질 수 있을 것 같습니다.

독자에게는 클라우드 프론티어 모델 의존도가 비용·규제 양면에서 흔들린다는 신호임. local LLM 도구 재점검과 애플 하드웨어 동향 추적이 단기 우선순위로 부상함.
