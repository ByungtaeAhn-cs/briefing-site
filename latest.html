KIST 이제현, 인용 논문 자동 분석 도구 공개와 Opus 5 회귀 신호

AI의 궁극적 가치를 "인간의 편견을 넘어서는 다학제 연구의 시스템화"로 규정하는 철학적 발언에서 출발해, 그 지향을 구현한 신규 연구도구를 공개함. 3~4개월 전 착수해 **paper curation** 패키지로 정리한 결과물의 응용 사례임.

특정 논문을 입력하면 인용 논문들을 수집해 후속 연구 전개를 시각·텍스트로 정리해주는 도구임. 예시로 "Can LLMs Generate Novel Research Ideas?"(arXiv:2409.04109) 인용 41편 중 PDF 39편을 확보해 "LLM이 제시하는 가설의 퀄리티"를 질의함. 도출된 결론은 **LLM이 자율 가설 생성기로는 부족**하나 도구·검증 루프·인간 심사가 결합된 active environment 내 아이디어 확장기로는 유효하다는 것. **Virtual Lab 나노바디** 사례에서 발현 성공률 90% 이상이나 실제 결합 기능을 보인 것은 일부에 그침. 별건으로 코딩 도구 사용 소감도 공유함.

예전같았으면 한참을 내려받고 읽거나 AI들과 씨름했어야 할 일이 클릭 한번으로 정리되었습니다.
Opus 5한테 코딩 맡겼더니 일을 여러번 하게 돼서 다시 GPT-5.6-Sol에게 맡기는데.. 저만 그런가요? Opus 5 적잖이 실망스럽네요

문헌 리뷰 자동화를 개인 연구 파이프라인으로 내재화한 실전 사례이자, LLM 가설 생성 능력에 대한 현시점 학계 컨센서스("확장기 O, 생성기 X")를 압축한 진단임. Opus 5 코딩 품질에 대한 현장 실망 신호로 **GPT-5.6-Sol 회귀** 흐름 주목.

허민, Codex 라이브 모드와 ASIDE로 재편되는 개인 워크플로우

모바일 앱에서 Codex가 사라진 상황을 계기로, 라이브 음성 모드와 브라우저 에이전트 **ASIDE** 조합을 중심으로 한 오늘의 실전 사용기 공유. GPT-5.6 Sol Medium fast 기준 200달러 요금제 70% 소진, 로컬·쓰레드·웹 ChatGPT까지 단일 메인 쓰레드에서 오케스트레이션 중임.

핵심 도구별 포지셔닝을 명확히 정리함. **울트라브라우저**는 몇 분 수준 단발성, **울트라코드/goal**은 며칠 단위 장기 실행, **ASIDE**는 브라우저 에이전트 최강이라는 구도. Lovart 영상·이미지 제작에도 모바일 Codex + ASIDE 조합 활용, 결과물은 테일스케일이나 크롬 리모트로 확인함. 추가로 이상수 님이 만든 **홈텍스 종소세/부가세 스킬**(lbiz-partners/hometax-doum)로 부가세 신고를 직접 완료, 16~17년 사업 인생 최초 자가 신고 사례임. 기존 세무대행 대비 최대 500분의 1 비용까지 절감 가능하다는 계산 공유. 기업 협업 도구로는 Block의 **Buzz**(에이전트 네이티브 이벤트 로그 기반 워크스페이스)를 슬랙 대체 후보로 지목함.

코덱스에서 라이브 모드 꼭 써보세요. AI사용하면 브레인롯 된다고 하는데 여러분의 뇌를 깨울수 있습니다. 모든 작업을 하나의 메인 쓰레드에서 오케스트레이션 할수 있습니다.
아마 앞으로 모든 산업들이 이렇게 대체될겁니다.

모델 성능이 아니라 **암묵지 격차**가 활용력을 가른다는 관점 재확인. 세무 자동화 사례는 도메인 대체 속도의 구체적 벤치마크로, Codex 라이브 + ASIDE + 스킬 조합이 단순 자동화가 아닌 산업 대체 레버임을 보여주는 신호. 아임웹 페이지 전면 개선 착수와 5주 유튜브 부트캠프 1기 10명 모집 예고도 함께 나옴.
