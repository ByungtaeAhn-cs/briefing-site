밤사이 쏟아진 신규 모델 릴리스를 따라가는 피로를 토로하며, 성급한 소개 콘텐츠 대신 직접 돌려본 체감을 확보한 뒤 영상화하는 본인 원칙을 재확인함. 하드웨어 영역은 본인도 약하다며 웹서치와 이미지·사운드·영상 녹화를 제미나이에 물어보는 우회 경로 언급.

핵심 주장은 **토큰 절감 수치의 비이식성**임. 벤더가 제시하는 절감률은 각자의 자동화 구성에 따라 달라지므로 Input/Output 토큰을 스스로 측정해 비교해야 한다는 입장. 모델 교체 시점에 맞춰 스킬류 아웃퍼폼 여부를 정성 테스트할 계획도 밝힘. 실사례로 **300만원 규모 앙상블 자동매매**를 공개 — gpt 5.6 sol, opus 5, deepseek pro v4 를 앙상블해 의사결정하는 구성이며, no quant·지식관리·자산배분 포트폴리오 로직 기반이라 스트레스가 없다고 평가. 반면 미니PC에서 돌리는 저배 선물 스윙 쪽은 스트레스가 크다고 대비시킴. 자동화를 선호도 기준으로 3분류: 하기 싫은 쪽은 컨설팅 등 본업, 좋아하는 쪽은 투자, 싫지만 생계상 필요한 쪽은 콘텐츠.

토큰 사용량이 줄였다 이런거는 각자 개인이 작업하는 자동화 상황이 달라서 Input / output token 스스로 측정해보고 비교해봐야합니다
